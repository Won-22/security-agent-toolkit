  - 쓸 내용: 「X: 평균 … ms · 지터 … ms / Y: 평균 … ms · 지터 … ms / Z: 손실 … %」

  - 쓸 내용: ① 회선 이름 하나 ② 지연 · 지터 숫자를 써서 이유
  - 답: Y 가 더 나쁘다. 지연 26ms 로 좋아보이지만, 지터 38ms 으로 상시로 연결되어있는 화상회의에선 딜레이가 생기기 때문이다.

### 문제 5-2 · 내 PC 의 ping 으로 지터 구하고 담당자의 보고 평가하기

  - 쓸 내용: 「응답 열 개: … / 평균 … ms · 손실 … % / 지터 … ms」
  - 답: 응답 10개 / 평균 35.2ms / 손실 0 / 지터 0.22

- (나) 위 ping 기록에서 오전과 오후에 **서로 달라진 조건**을 모두 적고, 「무선이 원인」이라고 확정할 수 있는지 적어 주세요.
  - 쓸 내용: ① 달라진 조건 이름을 모두(PC · 연결 방식 · 대상 주소 · 시각 중) ② 「확정할 수 있다 / 없다」와 이유

- (다) 🔍 무선이 원인인지 확인하려면 무엇을 같게 맞추고, 무엇 하나만 바꿔 다시 재야 하나요?
  - 쓸 내용: ① 같게 맞출 조건 ② 바꿀 조건 하나 ③ 몇 번 재는지
  - 답: PC, 주소, 시간을 다 같게 맞추고 무선/유선을 각 10번씩 재서 다시 재야한다.

### 문제 6-1 · 지터 함수 직접 만들기

- (가) 직접 만든 `jitter` 함수를 독스트링과 함께 아래 코드 블록에 붙여 넣어 주세요.
  - 쓸 내용: 독스트링을 쓴 함수를 복사해 아래 코드 블록에 붙여 넣기
  - 답:
```
def jitter(got):         # 받은 값 리스트 got 으로 지터를 구해 리턴하는 함수이다. 이 함수를 직접 만든다
    total = 0           
    for i in range(1, len(got)):
        total = total + abs(got[i] - got[i - 1])
    return total / (len(got) - 1)          
```

- (나) 함수를 채운 뒤 실행해 나온 세 줄을 그대로 옮겨 적어 주세요.
  - 쓸 내용: 터미널 출력 세 줄을 복사해 붙여 넣기
  - 답:
회선 A | 지연 21.9 ms | 지터 1.1 ms | 손실 0 %
회선 B | 지연 42.3 ms | 지터 54.3 ms | 손실 0 %
회선 C | 지연 41.0 ms | 지터 1.7 ms | 손실 30 %

- (다) `jitter` 함수의 리턴값은 무엇이고, `measure` 의 어느 줄에서 어떻게 쓰이나요?
  - 쓸 내용: ① 리턴하는 값이 무엇인지 ② 그 값을 받는 줄(`measure` 안)
  - 답: 리턴 값은 지터이며, jitter_value = jutter(got) 받는다.

- (가-2) 그 구간은 우리 회사 쪽일까요, 바깥(통신사)일까요? 근거를 적어 주세요.
  - 쓸 내용: ① 「사내 / 바깥」 하나 ② 근거(사내 홉의 시간 또는 장비 이름)
  - 답: 바깥 / 사내 통신은 시간이 얼마 걸리지 않지만, 사내 -> 바깥으로 이동할 때 많이 소요된다.

- (나) 🔍 표 2 의 4번 홉은 60 ms 로 큰데 실제 장애가 아니라고 봅니다. 그 근거는 무엇인가요?
  - 쓸 내용: ① 4번 홉의 뒤 홉 시간 ② 그것이 무엇을 뜻하는지
  - 답: 7ms 이건 4번홉이 트레이서트 를 해서 그런 것이다.

  - 답: 해당 측정은 전체 결과가 아닌, 한 시각의 값임으로 단정할 수 없으며, 동일한 증상이 반복되는지 확인을 하기 위해 매 시각마다 동일한 조건으로 측정해야한다.

  - 쓸 내용: 고객이 바로 읽을 수 있는 한 문장(우리 구간 상태, 원인 구간, 요청할 곳)
  - 답: 우리 구간은 정상이지만, 통신사 중계장비와 해외연결지점 사이에 지연이 있다. 통신사에 확인 요청 하겠다.
