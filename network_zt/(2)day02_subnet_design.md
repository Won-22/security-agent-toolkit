### 문제 2-1 · 내 IP 를 2진수로

- (가) 두 번째 파일(`warmup_2_1b.py`, 내 IPv4 주소)의 출력 네 줄:
192 11000000 / 168 10101000
10 00001010 / 25 00011001

- (나-1) `format(number, "08b")` 가 마디 하나의 10진수를 어떤 형태의 글자로 바꾸는지, 내 출력 한 줄을 예로 들어 설명하세요.
  - 답: format(number, "08b") 는 number에 들어간 숫자를 이진법으로 바꾼다.
  예시로 10이 들어가면 최대 255 인 8자리에서 00001010 으로
  
- (나-2) `"08b"` 에서 `08` 을 빼고 `"b"` 만 쓰면 `10` 은 어떻게 출력되나요?
  - 답: 8자리가 아닌 그냥 이진법으로 출력된다 1010

- (나-3) 마디마다 8자리로 맞춰 써야 하는 이유를 설명하세요.
  - 답: IPv4는 8비트씩 4자리로 나눠쓰는 구역이라 정확히 8자리로 4개구역을 써야 구분 할 수 있다.

- (다-1) IPv4 주소가 32비트라는 것과 마디 하나가 `0` ~ `255` 사이의 값만 가진다는 것은 어떻게 이어지나요? 마디 수와 비트 수를 근거로 설명하세요.
  - 답: IPv4는 8비트씩 4자리로 이뤄지고, 0~255 사이 값만 들어가는 이유는 8비트는 8자리로 모두 1일 경우 11111111 = 255 / 모두 0일 경우 = 0 
  따라서 0~255 사이 값만 가질 수 있기 때문이다.

- (다-2) 32비트로 만들 수 있는 주소의 개수: 2를 32번 곱한 개수

- (다-3) 그 개수가 나오는 계산 과정을, 비트 한 자리에 들어갈 수 있는 값의 가짓수와 자리 수를 넣어 단계별로 설명하세요.
  - 답: 비트 한 자리에는 0 또는 1 두 가지 값만 들어갈 수 있음.
      IPv4 는 32자리이므로 2 를 32번 곱한 개수만큼의 주소를 만들 수 있고
      마디 하나는 256가지(0~255)이고, 네 마디를 곱한 256 × 256 × 256 × 256 도 같은 값이다.

- (다-4) 이 수의 한계가 사설 IP 와 NAT 를 쓰게 된 것과 어떻게 이어지는지 설명하세요.
  - 답: 마스크 · 망 경계 계산이 모두 이 8비트 단위로 이루어지므로, 2진수로 펼칠 줄 알아야 경계를 검산할 수 있습니다.

### 문제 2-2 · 내 주소는 사설일까 — 인터넷이 보는 내 주소

- (가) `ipconfig` 의 내 IPv4 주소 · `curl` 로 본 공인 IP:
ipconfig = 192.168.100.65 / curl = 1.245.252.171

- (나-1) 🔍 내 IPv4 주소는 2.2 표의 어느 범위에 들어가며, 그래서 사설과 공인 가운데 무엇인가요? 범위의 시작 주소와 끝 주소를 근거로 판정하세요.
  - 답: 192.168.0.0 ~ 192.168.255.255 범위 이며 사설 IP에 해당된다

- (나-2) `curl` 로 본 주소는 사설과 공인 가운데 무엇인가요? 2.2 표의 세 범위와 맞춰 본 근거를 들어 설명하세요.
  - 답: 공인IP 사유는 사설 IP 범위 어디에도 해당하지 않는다.

- (나-3) 관제 로그의 출발지 주소가 `172.20.5.6` 과 `172.32.5.6` 이라면, 각각 내부망 장비와 외부 주소 가운데 무엇으로 먼저 분류해야 하나요? 2.2 표를 근거로 설명하세요.
  - 답: 172.20.5.6 은 사설로 내부망 장비로 분류하고, 172.32.5.6 은 사설 IP범위를 벗어나기에 공인IP임으로 외부 주소로 분류해야한다.

- (다-1) 외부 서버 로그에 남은 출발지 IP 만으로는 내부망의 어느 PC 인지 특정할 수 없는 이유를 NAT 의 동작으로 설명하세요.
  - 답: 사설IP 는 인터넷에서 쓸 수 없기에 공유기를 통해 공인IP로 바꿔 보내고, 응답이 돌아오면, 다시 사설IP로 변경해서 알려준다 이렇기 때문에 외부 서버에는 공유기의 공인IP만 남는다.

- (다-2) 정적 NAT 과 동적 NAT 은 사설 IP 와 공인 IP 를 연결하는 방식이 어떻게 다른가요?
  - 답: 정적 NAT는 사설IP 와 공인 IP를 1:1로 배정해서 고정값으로 두고 사용한다 반면에, 동적 NAT는 보유하고 있는 공인IP 만큼 사설IP를 변환시켜주고 똑같이 1:1 이지만, 요청하는 순서대로 배정하기 때문에 항상 변경된다.

- (다-3) 사원 PC 여러 대가 인터넷을 쓸 때는 동적 NAT 을 쓰는 이유는 무엇인가요? 동적 NAT 환경에서 외부 로그의 공인 IP 로 PC 를 특정하려면 무엇을 함께 봐야 하는지와 이어서 설명하세요.
  - 답: 여러대가 인터넷을 사용할 때에는 정적NAT는 PC 개수 만큼 공인IP를 보유해야하지만, 동적NAT를 사용하면 적게 보유해도 반납한 것을 사용하면 되서 제한이 없다 또한, 흔적이 남지않아 보안상 이유도 있다.
  외부 로그의 공인 IP만으로는 PC를 특정할 수 없고, 특정하려면 공인 IP와 함께 접속 시각을 보고, 그 시각의 NAT 변환 기록에서 사설 IP를 찾아야 PC를 특정할 수 있다.

- (다-4) 인터넷에서 회사 내부망의 웹 서버에 접속하게 하려면 정적 NAT 과 동적 NAT 가운데 어느 방식이 맞는지 이유와 함께 설명하세요.
  - 답: 정적NAT / 외부망에서 회사 내부망에 들어온다는 것은 아무나 접속을 허용하면 안되기에 사전에 배정된 공인IP를 통해서 접속하게 해야한다.

### 문제 3-1 · 내 서브넷 마스크 읽기

- (가-1) 내 서브넷 마스크 · CIDR · 주소 수 · 쓸 수 있는 수: 
255.255.0.0 / 16 / 65536 / 65534

- (가-2) 내 IPv4 주소의 망 부분 · 장비 부분:
192.168.0.0 / 0.0.100.65

- (나-1) 🔍 내 서브넷 마스크를 2진수로 펼쳤을 때 1 인 비트와 0 인 비트가 각각 주소의 어느 부분을 가리키는지, 1 이 8개인 마디의 수를 근거로 설명하세요.
  - 답: 11111111.11111111.00000000.00000000 
        (192/망) (168/망) (100/장비) (65/장비)

- (나-2) 내 마스크에서 CIDR 숫자가 어떤 계산으로 나오는지 1 이 8개인 마디의 수를 넣어 설명하세요.
  - 답: 255.255.0.0 을 2진수로 변형하면 11111111.11111111.00000000.00000000 인데
  여기에 표시된 1을 모두 더하면 16개 따라서 CIDR은 /16 이다.

- (나-3) 같은 교실의 다른 PC 와 비교했을 때, 망 부분과 장비 부분 가운데 어느 쪽이 같고 어느 쪽이 다른가요? 그렇게 되는 이유를 「같은 망」의 뜻과 이어서 설명하세요.
  - 답:같은 교실에 다른 PC와 동일한 IPv4 부분은 192.168.0.0 부분이다. 같은 망에 연결되어 있기 때문에 2번째 대역까진 동일하며, 그 이후 3,4번째 부분은 장비대역이라 다르다.

- (다-1) 내 마스크를 기준으로 `192.168.10.25` 와 `192.168.20.25` 가 같은 망인지 판정하고, 비교해야 하는 마디를 짚어 근거를 설명하세요.
  - 답: 같은 망이다. 내 서브넷 마스크는 255.255.0.0 으로 2번째 대역까지 같은 망으로 구분하는데 문제에 명시된 2개의 IPv4는 2번째 대역까지 모두 일치하기에 같은 망이다.

- (다-2) 같은 두 주소를 `/24` 마스크로 판정하면 결과가 어떻게 달라지나요?
  - 답: /24로 판정할 경우 다른 망이 된다. 왜냐하면 /24는 서브넷 마스크로 표현했을 때
  255.255.255.0 으로 3번째 대역까지 IPv4 가 일치해야 같은 망으로 구분하기 때문이다.

- (다-3) 마스크에 따라 판정이 달라진다는 사실이 통신 경로와 방화벽 규칙을 정할 때 왜 중요한지 설명하세요.
  - 답: 마스크에 따라 비슷해 보이는 IPv4 여도 통신 경로가 달라지며, 방화벽 즉, 보안구역을 설정할 때 특정 대역 IPv4만 접속을 허용하고 불가하게 하는 판단이 되기 때문이다.
