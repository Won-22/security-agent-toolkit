## 오늘 새로 쓴 명령
touch, cp, mv, rm, Tab 자동 완성
touch : 빈 파일을 만든다.
cp : 파일을 복사한다
cp -i : 폴더 자체를 복사한다
cp -r : 특정 파일을 폴더 안으로 복사하는데, 중복되는 파일이 있으면 물어본다
mv : 파일명을 변경하거나, 폴더로 옮긴다.
rm : 파일이나 폴더를 삭제한다.
rm -r : 폴더와 내부의 파일까지 지운다
rm -ri : 폴더와 내부의 파일까지 지울 때 물어본다
Tab : 자동완성

## 찾은 옵션
폴더째 복사 -i  / 덮어쓰기 전에 묻기 -r  / 폴더째 지우기 -r

## mv 의 두 가지 쓰임
이름 바꾸기: mv 뒤에 이름을 쓰면, 이름이 변경됨
옮기기: mv 뒤에 폴더명을 쓰면 파일 폴더로 옮겨짐
